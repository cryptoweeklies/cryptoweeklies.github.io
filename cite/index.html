How to cite

Name the site, the page the figure came from, its address and the reading date:

CryptoWeeklies. "[Page title]." [Page URL]. Reading dated [date printed beside the figure]. Accessed [the date you read it].

For example:

CryptoWeeklies. "Bitcoin (BTC) Risk Score: Is It Overvalued Right Now?" https://cryptoweeklies.com/BTC_Price_TWAP_Gravity_Analysis. Reading dated 2026-11-14. Accessed 2026-11-14.

In running text, “according to CryptoWeeklies (cryptoweeklies.com), in a reading dated …” with a link to the page is enough. Please link the page the figure is on rather than the homepage, so a reader can see the chart behind it.
