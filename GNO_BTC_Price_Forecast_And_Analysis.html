Description

This analysis provides a forecast of GNO prices using a Seasonal ARIMA model with Box-Cox transformation. The forecast includes different scenarios:

  • Bear Case: The lower bound of the confidence interval, representing a pessimistic scenario.
  • Base Case: The average forecasted price.

The confidence levels used are 68%, 95%, and 99.7%, which means there is a corresponding probability that the actual price will fall within the Bear and Bull case range for each confidence level.

The purpose of this model is to help investors understand potential future price movements and make informed decisions based on different market scenarios.
